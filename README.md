# Introductory Statistics - Curious2Study

## Course Overview

Introduction to statistics designed for students with little to no prior statistical background. This course teaches you to understand data, make informed decisions based on evidence, and think critically about statistical information.

## Course Philosophy

Statistics is essential for informed decision-making in everyday life. From evaluating health claims to understanding research findings, statistical literacy matters. This course teaches you to think statistically and question statistical arguments.

## Course Materials

Each section includes:
- **Video Lectures:** Conceptual explanations with real-world examples
- **Study Guides:** Key concepts and important principles

## How to Use This Course

1. Watch the video lectures for each section
2. Read the study guides to reinforce learning
3. Focus on understanding and interpretation

## Learning Approach

This course emphasizes:
- Conceptual understanding over calculation
- Real-world applications and examples
- Critical thinking about data
- Recognizing statistics in everyday life
